# adsense

Next.js multisite information network for AdSense approval preparation.

## Sites

- `licensemoa.co.kr`: 시험일정센터
- `conferenceinfo.co.kr`: 전국행사노트
- `money1000.co.kr`: 청년주거도움
- `business100.co.kr`: 사장님지원캘린더
- `publicguide.co.kr`: 공공시설가이드

## Development

```bash
pnpm install
pnpm dev
pnpm build
```

## Notes

The app includes site-specific canonical URLs, sitemap generation, robots.txt, policy pages, contact/source pages, and the AdSense account verification meta tag.
